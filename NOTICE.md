# Notice

## Everything here is synthetic
No real person's data was used to create this package. Every person, household, address, company, record and text is generated by a program. Any resemblance to real people is coincidental.

Identifier formats are realistic, but they are drawn from ranges that real people and accounts do not use, where such ranges exist:

| Identifier | Range used |
|---|---|
| HETU (Finnish personal identity code) | Individual numbers 900–999. This range is reserved for temporary identifiers and is never used in permanent identity codes from the population register. Every code is unique within the package. |
| IBAN | Valid checksums, bank identifier starting with 9, which is not used by Finnish banks. |
| Payment cards | Public test BINs (411111, 400000, 424242, 555555, 510510, 222300) with valid Luhn digits. |
| Email addresses | Only reserved `.example` domains (RFC 2606). |
| IP addresses | RFC 5737 documentation ranges, 100.64.0.0/10 shared address space, private 10.0.0.0/8, and IPv6 2001:db8::/32. |
| Phone numbers, plates, metering point IDs, property IDs | Random values in Finnish formats; a match with a real one is coincidental. |

All organisations acting as data controllers are fictional:

- Aurajoki Regional Hospital
- Aura Transit
- Lounaisvirta Verkko Oy
- Saaristo Bank
- Meridian Logistics Oy
- Kaarna Care Oy
- Aallokko Telecom Oy
- Southwest Joint Service Centre
- the named schools

Real municipality and postcode names are used as geography only.

## Geography
Postcode centroids come from GeoNames (https://www.geonames.org/), licensed CC BY 4.0, via the conversion at github.com/zauberware/postal-codes-json-xml-csv. Population counts per postcode, street names and building locations are synthetic and are not official statistics.
